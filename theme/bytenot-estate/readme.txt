A reusable block theme for real-estate companies. Pair it with the Property Core plugin for listings, projects, localities and lead capture.

== Description ==

Bytenot Estate is a block theme: colours, type, spacing and radii live in theme.json, the layout in templates, parts and patterns. Nothing about one company is hard-coded; the site logo, title and tagline, menus, contact details and footer text are all content.

Figtree (SIL Open Font License) is expected at assets/fonts/figtree-variable.woff2 and assets/fonts/figtree-italic-variable.woff2. The theme falls back to the system sans-serif until the files are present.
