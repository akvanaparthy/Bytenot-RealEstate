A reusable theme for real-estate companies. Pair it with the Bytenot Core plugin for listings, projects, localities and lead capture.

== Description ==

Bytenot Estate is a classic theme built from a designed prototype: colours, type, spacing and radii live in theme.json, the layout in PHP templates. Nothing about one company is hard-coded; the logo, title and tagline, menus, every text and photo (Customize › Bytenot Estate), contact details and the listings all are content.

Figtree (SIL Open Font License) is bundled under assets/fonts.
